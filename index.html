01 — AGROPREDICT

Smart Crop Price
Intelligence

A Flutter app that helps farmers decide where and when to sell for better profit — using live AGMARKNET government data, GPS-based mandi comparison, transport profit calculation, and Hindi voice support. Field-tested with 10+ farmers across Odisha and Jharkhand.

My father grows crops on our family farm. Observing harvest and selling decisions helped me identify the market-information challenges AgroPredict aims to address.

Farmers don't lose money growing crops.
They lose it selling them.

I visited farms across Odisha and Jharkhand. Sat with farmers and suppliers. Almost every farmer sells locally by default — not because it's the best price, but because they have no easy way to compare alternatives or know if the trip is worth it.

Every harvest, the same question came up at home — where should we sell? Different mandis offered different prices, but comparing them was difficult. AgroPredict started as an attempt to make that decision easier for my family and nearby farmers.

WHAT IT DOES

Nearest mandi detected from device location — distance and travel time estimated on-device
PROFIT CALCULATOR
Net profit after transport cost — calculated before the farmer makes the trip, not after
SELL / WAIT / MONITOR
Rule-based advice comparing current price against available mandi data — no ML model, transparent reasoning
VOICE OUTPUT
flutter_tts reads advice aloud in Hindi — farmer hears without needing to read the screen
CROP VARIETIES
Basmati vs Common vs Sona Masuri — because farmers think in varieties, not just crop categories
HINDI UI + VOICE INPUT

02 — REPSHIELD

Zero-friction
Emergency Response

A personal safety app for situations where every second determines user safety. One shake sends live GPS location to all trusted contacts simultaneously — no unlock, no delay, no steps between danger and help.

SHAKE-TO-SOS
Accelerometer (sensors_plus) detects shake above threshold — fires SOS protocol instantly, bypassing lock-screen barriers entirely. No unlock required.
LIVE GPS ALERT
Fetches device coordinates via geolocator, constructs a Google Maps link, and sends it via SMS to all trusted contacts simultaneously in a single trigger event.
STEALTH MODE
Discreet UI design for unsafe situations — the interface doesn't announce what the app is doing to anyone who might be nearby.
SHA-256 EVIDENCE LOG
Tamper-evident incident records using SHA-256 hashing — each entry is verifiable and detectable if altered.

03 — SENTINELPAY

IN PROGRESS

Real-time Payment
Fraud Detection

A fraud detection engine that scores every payment transaction live against an explainable rules engine — checking amount, velocity, and device recognition — before approving, flagging, or blocking. Every decision includes a clear breakdown of exactly why, not a black-box verdict.

WHY I BUILT IT

Most beginner payment projects are just forms that save data. I wanted to build something closer to what real fintech companies run internally — a system that actually reasons about risk, not just processes transactions. I also built a live fraud attack simulator that fires a burst of rapid transactions and shows the engine's response escalating in real time.

HOW IT WORKS

01
Submit
React frontend captures amount, payee, and device fingerprint
02
Score
Spring Boot runs independent fraud rules — amount, velocity, hour, device
03
Explain
Each triggered rule adds points + a plain-English reason
04
Decide
Total score → Approved / Flagged / Blocked verdict
05
Log
Full decision saved to PostgreSQL — survives server restarts
